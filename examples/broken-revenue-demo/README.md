# Broken revenue demo

Synthetic shop data, generated by [`generate.py`](generate.py) with seed `20260315`. No warehouse credentials.

[`models/buggy_revenue.sql`](models/buggy_revenue.sql) passes the demo's basic tests and SQL lint. It is still wrong: a refund join repeats line items, and `CAST(ordered_at AS DATE)` uses the UTC calendar date instead of America/New_York.

[`models/correct_revenue.sql`](models/correct_revenue.sql) is the reference. The contract is [`gross_item_revenue.contract.yaml`](gross_item_revenue.contract.yaml). The join path the grain helper walks is [`join_steps.json`](join_steps.json).

From the repository root:

```bash
uv sync
make demo
```

The command keeps the database in memory and prints the inflation and the two root causes. Pass nothing else; it does not read the network.
